情報セキュリティ管理体制

TSアセットマネジメント合同会社では、当社が管理・運営するシステムおよび情報資産の保護を目的として、情報セキュリティ管理の責任者を定めています。

セキュリティ責任者は、社内システムの安全性の確認、アクセス権限の管理、脆弱性への対応および情報セキュリティ上のリスク管理を担当します。

The security lead's responsibilities include reviewing system security, overseeing access controls, coordinating vulnerability remediation, and managing information security risks.
