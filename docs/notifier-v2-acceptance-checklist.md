## E. ライセンスの失効（実測）

**ここは「解約したら止まる」ことを実際に確かめる節である。**
判定結果は KV に6時間キャッシュされるため、待つ代わりにキャッシュを消して確かめる。

### デバッグ手段（キャッシュを消す）

```powershell
# 1) いま入っているキャッシュの一覧を見る（キーは license:<ハッシュ>）
npx wrangler kv key list --binding LICENSE_CACHE --config workers/notifier-gate/wrangler.jsonc

# 2) 対象の1件を消す（<KEY> は上の出力から）
npx wrangler kv key delete "<KEY>" --binding LICENSE_CACHE --config workers/notifier-gate/wrangler.jsonc
```

> **TTL を短くする設定は用意していない。** 本番の Worker に検証用のつまみを
> 足すと、戻し忘れたときに「解約が反映されない」側へ倒れる。
> キャッシュを消すほうが、確かめたいこと（キャッシュが切れたあとの挙動）に
> 対して同じ結果を、あとに何も残さずに得られる。

| # | 作業 | 期待する結果 | 結果 | 実測・気づき |
| --- | --- | --- | --- | --- |
| E-1 | 認証設定シートの `NOTIFIER_ENTITLEMENT` を一時的に `plan:none` にする | ― | ☐ | |
| E-2 | 上のコマンドで対象の KV キャッシュを消す | 消える | ☐ | |
| E-3 | 録音アプリで［接続テスト］を押す | 「ご契約」が **「ご契約を確認できません」**（赤） | ☐ | |
| E-4 | 同じ画面の「ご契約:」の行を見る | **料金ページへのリンクが表示される** | ☐ | |
| E-5 | 通知タイミング＋2分後の予定を作り、待つ | **通知は届かない** | ☐ | |
| E-6 | シートの `notify_queue` を開く | 行が増えていない（判定が空で返っている） | ☐ | |
| E-7 | `NOTIFIER_ENTITLEMENT` を `all_active` へ戻し、KV を消す | ― | ☐ | |
| E-8 | ［接続テスト］を押す | 「ご契約」が **「ご利用いただけます」**（緑）。料金リンクは消える | ☐ | |

> **E-5 は「不着信」だけで判定しない。** 通知が出ないことは、仕組みが動いていない
> 場合と区別がつかない。`notify_queue` に行が増えていないことまで見ること
> （V1 の受け入れ検証と同じ考え方）。
