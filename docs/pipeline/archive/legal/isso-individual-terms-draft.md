## 1. 一想（ISSO）個別規約（起案）

> **前文**
>
> 本個別規約は、TSアセットマネジメント合同会社（以下「当社」という。）が
> 本サービスの一機能として提供する「一想（ISSO）」（以下「本アプリ」という。）の
> 利用条件を定めるものである。本個別規約は、TSAM AI 利用規約（以下「基本規約」という。）
> 第2条第3項に基づき基本規約の一部を構成し、本アプリの利用について
> 基本規約と異なる定めがある場合は本個別規約が優先する。
>
> 本個別規約において別段の定めがない用語は、基本規約第1条の定義に従う。

### 第1条（定義）

1. 「本アプリ」とは、利用者が入力した着想をもとに複数の媒体向けの文章を生成し、
   その下書きの作成及び連携先サービスへの投稿を支援する機能をいう。
2. **「連携先サービス」とは、Threads（Meta Platforms, Inc.）、X（X Corp.）、
   note（note株式会社）その他、本アプリが投稿又は下書き作成の対象とする
   外部サービスをいう。**
3. 「投稿」とは、利用者の操作により、本アプリを通じて連携先サービス上に
   コンテンツを公開する行為をいう。

> **起案メモ**: 第2号が A-10 の中核。既存 第1条第5号の「AIプロバイダー」は
> *AI/機械学習/音声認識/画像認識の API 提供事業者* の定義であり、SNS は該当しない
> （inventory §4-1）。**この定義が無いと、第6条〜第8条・プライバシー6・8 が
> SNS を射程外にしたままになる。**

### 第2条（連携先サービスとの連携）

1. 利用者は、**自らが正当な権限を有するアカウントのみ**を本アプリに連携できる。
2. 連携先サービスの利用には各運営者の定める規約が適用される。連携又は投稿に起因して
   利用者と連携先サービスの運営者との間に生じた事項について、当社は責任を負わない。
3. **X との連携に必要な X API の認証情報は、利用者が自ら取得・登録するものとし、
   その管理及び利用に伴い発生する費用は利用者の負担とする。** 当該認証情報の
   取り扱いについては、**基本規約第6条（APIキーの取得及びAIプロバイダーとの契約）の
   定めに準じる。**
4. 当社は、連携先サービスのAPI仕様若しくは規約の変更又は審査状況により、
   特定の連携先サービスへの投稿機能を変更又は停止することがある。

> **起案メモ**: 第3項は素材のとおり基本規約第6条へ「準じる」形にした。
> 第6条を書き換えず、適用範囲だけを個別規約で広げる形になっている。
> **文章生成に用いる Gemini のAPIキーは、基本規約第6条が直接適用される**
> （Gemini は同第1条第5号の「AIプロバイダー」そのもの）ため、ここでは触れない。

### 第3条（投稿）

1. 本アプリからの投稿は、**連携先サービス上で不特定多数に公開される行為であり、
   公開後の完全な取り消しは困難である**ことを、利用者はあらかじめ了承する。
2. **投稿の実行は常に利用者自身の操作による**ものとし、当社が利用者に代わって
   投稿の実行を判断することはない。
3. 利用者は、投稿前に内容の正確性及び適法性を自ら確認する責任を負う。
   **AIにより生成された文章に誤りが含まれ得ることを踏まえ**、生成物をそのまま
   公開したことにより生じた結果についても同様とする。
4. 利用者は、第三者の権利を侵害する投稿、連携先サービスの規約に違反する投稿、
   スパムその他の迷惑行為のために本アプリを利用してはならない。

> **起案メモ**: 第3項は基本規約第10条（AI生成結果及び利用判断）の延長だが、
> **公開を伴う点で性質が違うため独立させた**（inventory §4-2）。
> 第4項は基本規約第11条（禁止事項）の特則にあたる。

### 第4条（予約リマインダー）

1. 本アプリの予約機能は、利用者が指定した日時に**通知を行うもの**であり、
   当社が利用者に代わって投稿を実行するものではない。
2. 通知は、利用者の端末、ブラウザ及び通知許諾の設定に依存する。**当社は通知が
   指定した日時に到達することを保証しない。**

> **起案メモ**: 素材に無いが、実装指示書 §2-4 の仕様（リマインダー方式）から
> **必要と判断して追加**した。利用者は「予約投稿」と聞けば代理投稿を期待するため、
> 明示が無いと期待と実装の差が苦情になる（inventory §4-3）。**要否は発注者判断。**

### 第5条（データの保存場所）

1. 利用者が本アプリで作成・生成したコンテンツ、連携先サービスのアクセストークン
   及び利用者が登録したAPIキーは、**利用者の端末のブラウザ内にのみ保存され、
   当社のサーバーには保存されない。**
2. 前項のデータは、**利用者が使用する端末及びブラウザごとに保存され、
   相互に同期されない。** ブラウザのデータを削除した場合、又はブラウザの設定に
   よっては、当該データは失われる。
3. 利用者は、必要に応じて本アプリのエクスポート機能により自らデータを保存する
   ものとする。**当社は、本アプリがバックアップの手段であることを保証しない**
   （基本規約第9条第4項）。

> **起案メモ**: 基本規約 **第6条第4項**が「APIキーの保存の有無、保存場所、保存期間
> 及び保護方法は、**本サービスの画面又はプライバシーポリシーにおいて別途表示する**」と
> 定めており、**その表示義務をここと `/pipeline/keys/` 画面で果たす**（inventory §3-2）。
> 第3項は基本規約第9条第4項の確認的規定。

### 第6条（本個別規約に定めのない事項）

本個別規約に定めのない事項については、基本規約の定めるところによる。
当社の責任の範囲及び制限については、**基本規約第16条（保証の否認）及び
第17条（損害賠償責任の制限）**が適用される。

> **起案メモ**: 独自の免責を書かず基本規約へ寄せた。基本規約の責任制限は
> **消費者利用者／事業者利用者で適用が分かれる**（第16条3項・第17条4項5項）ため、
> 個別規約側で独自の免責を書くとこの区分が壊れる。

## 2. プライバシーポリシー補遺（起案）

**プライバシーポリシーには個別化の仕組みが無い**（16節構成で機能別の入れ子が無い）ため、
**本体へ節を足す**形になる（inventory §1）。挿入位置の案は §3。

### 追加案：「N. 一想（ISSO）における取り扱い」

#### N-1. 取得・保存しない情報

当社は、本アプリにおいて次の情報を取得せず、保存しない。

- 利用者が作成・生成したコンテンツの本文（着想、文章、台本、下書き、投稿履歴）
- 連携先サービスのアクセストークン
- 利用者が登録したAPIキー

**利用者が登録した Gemini API キー及び生成の対象となる内容は、利用者のブラウザから
Google へ直接送信され、当社のサーバーを経由しない。**

Threads への投稿送信が当社のサーバーを一時的に中継する場合においても、
**当社は本文及びトークンを保存せず、ログにも記録しない。**

#### N-2. 取得する情報

1. 利用者識別子（既存の登録情報に紐づくID）
2. **Threads への投稿の回数、日時及び結果区分**（共有上限の公平な管理のため。
   **投稿の本文は含まない。**）
3. 通知（Web Push）の購読情報
4. 上限、許可リストその他のサービス設定

#### N-3. 削除

コンテンツ、APIキー及びアクセストークンは**当社が保存していないため**、
本アプリ内の「データを全消去」又はブラウザのサイトデータの削除により、
**利用者自身が完全に削除できる。**

Threads との連携は、本アプリ内での解除に加え、Meta アカウントの
「アプリとウェブサイト」設定からも取り消すことができる。

N-2 の(1)から(4)までの情報については、**プライバシーポリシー第12節（開示等の請求）に
定める窓口への請求又は退会**により、当社が削除する。

#### N-4. 外国にある第三者への提供（第8節への追記）

第8節に掲げるもののほか、次の事業者が外国に所在し、又は外国で個人データを
取り扱う場合がある。

- Meta Platforms, Inc.（米国）
- X Corp.（米国）

> **起案メモ**: 素材に無いが**第8節の実効性のために必要と判断して追加**した。
> 現行第8節は「Stripe、Google又はAIプロバイダー」しか挙げておらず、
> **Meta と X が抜けている**（inventory §4-1）。

#### N-5. ローカルストレージ（第11節への追記）

第11節の「Cookie、セッションストレージ又はローカルストレージ」には、
**IndexedDB を含む。** 本アプリでは、利用者が作成・生成したコンテンツの
保存に IndexedDB を用いる。

> **起案メモ**: これも素材に無いが必要。現行第11節は用途を
> 「利便性向上」等としか書いておらず、**本体データの保存先である**ことが
> 読み取れない（inventory §4-5）。
