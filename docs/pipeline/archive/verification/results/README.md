# 検証結果

`T1.md` 〜 `T6.md` に**人が**判定と考察を書く。`raw/*.json` はスクリプトが書く。

## 書き方

各トラックのファイルは次の形にする。テンプレートは [_TEMPLATE.md](./_TEMPLATE.md)。

判定は3値（検証計画 §1）。

| 判定 | 意味 |
| --- | --- |
| **Go** | そのまま進める |
| **条件付きGo** | フォールバックを採れば進める。何を採るかを明記する |
| **No-Go** | 進めない。仕様変更が要る。要件定義書 v0.2 への反映事項に挙げる |

## 書いてはいけないもの

`docs/` と同じ基準。**リポジトリは公開されている。**

- アクセストークン・APIキー・署名シークレット
- Resumable Upload のセッションURL（それ自体が資格情報として働く）
- 実在するメールアドレス
- スプレッドシートID・内部URL
- 利用者の実データ

`lib/record.mjs` の `redact()` が既知の形を伏せるが、**万能ではない。**
コミット前に自分の目で確認すること。一度コミットすると履歴に残り、
あとから消しても取り消せない。
