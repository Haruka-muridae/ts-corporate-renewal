T6-5: Web Push で予約リマインダーが成立するか

実装指示書 §2-4 は、サーバーがトークンを持たないため代理投稿ができないとして、 予約投稿をリマインダー方式へ読み替えている。 AC-05 の読み替えが成立するかどうかが、この項目に懸かっている。

ローカル通知では検証にならない。 画面を閉じている・端末がスリープしている ときに届くかどうかが問われているのに、setTimeout はページが生きている間しか動かない。 本物のプッシュ（VAPID 署名つきの送信）でしか確かめられない。 このページは購読までを行い、送信は別途サーバーから行う。
