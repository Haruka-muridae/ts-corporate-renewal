T1-6: ブラウザから Threads API を直接呼べるか（CORS）

通れば、投稿の無状態中継APIを実装しなくてよくなる。本文がサーバーを 一度も通らなくなるため、実装指示書 §2 の非保持の主張が「記録しない」から 「そもそも通らない」に強くなり、審査での説明も楽になる。
