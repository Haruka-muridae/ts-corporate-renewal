# 凍結した検証トラック

**凍結日**: 2026年8月7日
**根拠**: [implementation-guide.md](../../docs/pipeline/implementation-guide.md) v0.5 §8（拡張フェーズ）

動画化（TTS・レンダリング）と YouTube 連携が MVP 対象外になったことに伴い、
対応する検証トラックを凍結した。

**削除していない。** 拡張フェーズを再開するときに、そのまま動かせる状態で残してある。

---

## 凍結したもの

| 対象 | 元の目的 | 凍結理由 |
| --- | --- | --- |
| **T3**（YouTube Data API・全8項目） | 公開アップロードの成立条件を確定する | YouTube 連携が MVP 対象外（guide §8） |
| **T5**（TTS・動画レンダリング・全6項目） | 品質・時間・コストの実数を得る | 動画化が MVP 対象外（guide §8） |
| **T6-2**（レンダリングジョブの冪等性） | 二重実行で二重生成しないこと | **対象が消滅**（下記） |

### T6-2 だけ理由が違う

T3 と T5 は「MVP でやらないから凍結」だが、**T6-2 は検証対象そのものが無くなった。**

元は「予約投稿ジョブとレンダリングジョブ」が対象だった。

1. 予約投稿は guide §2-4（v0.4）でリマインダー方式になり、**サーバーが代理実行する
   ジョブが消えた**
2. 残っていたレンダリングも guide §8（v0.5）で拡張フェーズへ送られた

結果、**サーバー側に冪等性を要するジョブが1つも無い。** 投稿の冪等性は利用者ローカルの
キューと `idempotencyKey` で担保する（T6-3 側の責務）。

| 項目 | なぜ残るか |

| **T1（Threads）・T2（X）** | MVP の中心 |

**YouTube 台本の生成（FR-040〜044）は Phase 1 に残る**（guide §8-2）。
テキスト成果物までが対象で、音声化・動画化・アップロードを行わない。
台本生成そのものを検証するトラックは元から無く（AC-01 の範囲）、
ここで凍結したものには含まれない。

## 動かし方（凍結中でも動く）

凍結トラックは「すべて実行」には含まれないが、**名指しすれば動く。**
再開時にファイルを書き換える必要はない。

```powershell
node verification/pipeline/run.mjs            # 凍結を除いた MVP 対象だけ
node verification/pipeline/run.mjs T3         # 凍結中の T3 を名指しで動かす
node verification/pipeline/run.mjs --list     # ★凍結 の印つきで一覧
```

## 再開するときに必ずやること

**外部APIの仕様は凍結中に変わる。** 以下を「変わっている前提」で読み直してから着手する。

| 確認するもの | 場所 | 特に変わりやすい点 |
| --- | --- | --- |
| YouTube 監査の申請文面 | `docs/pipeline/phase0/review-submissions.md` §4 | 監査フォームの項目・必要なスクリーンショット |
| Google OAuth 検証の申請文面 | 同 §3 | **`youtube.upload` のスコープ分類**（センシティブ／制限付き）。分類が変わると費用と期間が桁で変わる |
| 発注者の作業手順 | `docs/pipeline/phase0/owner-tasks.md` 末尾「凍結した作業」 | Console の画面構成 |
| レンダリング方式の比較観点 | `tracks/T5-media.mjs` の T5-6 | ffmpeg.wasm の COOP/COEP 要件、SharedArrayBuffer の可否 |
| Resumable Upload 検証ページ | `probes/resumable-upload-youtube.html` | CORS の `Access-Control-Expose-Headers` に `location` が含まれるか |

### 再開時にスコープが戻ること

拡張フェーズを再開する場合、guide §8-1 の表にある以下も併せて戻す。

- 要件 7.6（FR-050〜055・動画自動生成）
- 受入条件 AC-06 / AC-07
- 環境変数 `GOOGLE_CLIENT_ID` / `_SECRET` / `TTS_API_KEY` / `RENDER_WORKER_*`
- guide §2-2 の「生成動画・音声」の置き場所の行

> **guide §6-7（FR-043 シーン分割の扱い）の結論次第で、再開時の作業量が変わる。**
> (a) を採って FR-043 も拡張フェーズへ送っていた場合、シーン分割の実装から始まる。
> (b) を採っていた場合は、シーン分割済みの台本がすでにある状態から始められる。
