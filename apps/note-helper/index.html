Note Draft Helper

Note Draft Helper

生成済みの記事を取得し、noteへの登録を補助します。記事のコピー、noteの起動、記事状況の更新を1画面で行えます。noteへの投稿はご自身の操作で行っていただく必要があり、このアプリが自動で投稿することはありません。

GAS設定

GAS WebアプリのURLを保存します。この端末のブラウザ内にのみ保存され、外部へは送信されません。

記事取得

記事状況が「記事生成完了」の記事を1件取得します。取得した記事は「取得済」になります。
