状態を確認しています…

まず準備をします

ボタンを押すと「このアプリは Google で確認されていません」という警告が出ます。 これは正常です。あなた自身がコピーしたスクリプトを、 あなた自身が承認する操作です。「詳細」→「（プロジェクト名）に移動」で続行してください。

あと1回だけ、設定の許可が要ります

公開を自動で行うために、Google 側で「Apps Script API」をオンにしてください。 この操作は最初の1回だけです。

設定ページを開く

  1. 開いたページで「Google Apps Script API」をオンにする
  2. このサイドバーへ戻る（自動で次へ進みます）

オンになるのを待っています…

この環境では、手動で公開してください

このスクリプトに紐づく Google Cloud のプロジェクトの都合で、 ワンボタン公開が使えません。下の手順で同じ結果になります。 所要1分ほどです。

  1. 上部メニューの「デプロイ」→「新しいデプロイ」
  2. 種類の選択（歯車）→「ウェブアプリ」
  3. 「次のユーザーとして実行」＝自分
  4. 「アクセスできるユーザー」＝全員
  5. 「デプロイ」を押す
  6. このサイドバーへ戻って、下の［公開できたか確かめる］を押す

ワンボタン公開を使えるようにする（技術者向け・任意）

Google Cloud のプロジェクトを自分で用意すると、以後は［公開する］が使えます。 通知の動作に違いはありません。

  1. Google Cloud で新しいプロジェクトを作る
  2. そのプロジェクトで Apps Script API を有効にする
  3. 同じプロジェクトで Google カレンダー API を有効にする （予定の読み取りに使います。これを忘れると公開後に同期が失敗します）
  4. スクリプトの「プロジェクトの設定」→「Google Cloud Platform プロジェクト」で、 作ったプロジェクトの番号へ切り替える
  5. メニューからこのサイドバーを開き直し、求められた権限を承認し直す

有効化のページを開く

公開します

ウェブアプリとして公開し、録音アプリから通知を受け取れるようにします。

最後に、録音アプリで仕上げます

下のボタンから録音アプリを開くと、接続とライセンスの設定が自動で完了します。

📱 録音アプリで仕上げる

このリンクには接続キーが含まれます。第三者へ渡さないでください。

設定は完了しています

通知の内容と受け取り方は、録音アプリの設定画面から変更できます。

録音アプリを開く

コードを貼り替えたときは（更新のしかた）

エディタで保存しただけでは、公開中のウェブアプリに反映されません。 新しいバージョンとして公開し直す必要があります。

公開しています…

公開URLは変わりません。録音アプリ側の設定はそのままで構いません。

手で行う場合:

  1. 上部メニューの「デプロイ」→「デプロイを管理」
  2. 公開中のものの鉛筆（編集）を押す
  3. 「バージョン」を「新バージョン」にする
  4. 「デプロイ」を押す

「新しいデプロイ」は選ばないでください。 URLが変わり、録音アプリ側の接続をやり直すことになります。

うまくいかないときは（手動で公開する）
  1. 上部メニューの「デプロイ」→「新しいデプロイ」
  2. 種類の選択（歯車）→「ウェブアプリ」
  3. 「次のユーザーとして実行」＝自分
  4. 「アクセスできるユーザー」＝全員
  5. 「デプロイ」→ 表示されたら、このサイドバーで［状態を読み直す］

すでに公開したことがある場合は、「新しいデプロイ」ではなく 「デプロイを管理」→ 既存のものを編集 → バージョンを「新バージョン」にして更新してください。 新しいデプロイを作るとURLが変わり、録音アプリ側の設定をやり直すことになります。
